# ⭐ Number, Star Pattern and Table Generator

## 📌 Project Overview
A menu-driven Python application that generates star patterns, number patterns, and multiplication tables based on user input. Generated patterns are displayed on the screen and saved automatically in `patterns.txt`.

## ✨ Features
- **Star Patterns:** Right Triangle, Pyramid, Inverted Pyramid and Diamond.
- **Number Patterns:** Number Pyramid, Floyd's Triangle and Pascal's Triangle.
- **Tables:** Multiplication Table and Multiplication Table Grid.
- **Custom Input:** Choose pattern size and symbols (`*`, `#`, `@`, `$`, `+`).
- **File Handling:** Automatically saves generated patterns in a text file.

## 🛠️ Technologies Used
- Python
- Visual Studio Code
- Built-in Python modules and functions

## 📚 Python Concepts Used

| Concept | Purpose |
|---|---|
| Nested Loops | Pattern generation |
| Recursion | Factorial for Pascal's Triangle |
| Tuple and Set | Symbol storage and validation |
| Dictionary | Menu mapping and data storage |
| File Handling | Saving generated patterns |

## ⚙️ How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Execute:
```bash
python main.py
```
5. Select a menu option and follow the instructions.
## 💾 Output
All generated patterns are automatically saved in `patterns.txt` using append mode, preserving previously saved outputs.
